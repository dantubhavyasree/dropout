# my-research

Reproducing **Dropout: A Simple Way to Prevent Neural Networks from Overfitting**
(Srivastava et al., 2014), focusing on the MNIST feed-forward experiments.

We train the basic MLP (`784 -> 1024 -> 1024 -> 10`, ReLU, SGD lr=0.1 momentum=0.95)
on MNIST twice: **without dropout** and **with dropout** (hidden retention p=0.5,
inverted dropout as in Eq. (5) of the paper). All training runs in **Google Colab**
— no local GPU installation needed.

## Run it on Colab

1. Open `notebooks/Training.ipynb` in [Google Colab](https://colab.research.google.com).
2. Edit the `REPO_URL` in the first code cell to point at your GitHub repo, then
   **Run all**.
3. Repeat with `Evaluation.ipynb` and `Inference.ipynb`.
4. Commit the generated `results/` images back to the repo.

## Reference numbers from the paper (feed-forward MNIST nets)

| Model | Test error |
|---|---|
| Standard 2-layer net, 800 logistic units (Simard et al., 2003) | 1.60% |
| Dropout net, 3 layers, 1024 logistic units | 1.35% |
| Dropout net, 3 layers, 1024 ReLU units | **1.25%** |
| Dropout net + max-norm, 3 layers, 1024 ReLU units | 1.06% |
